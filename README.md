# KANTCODE
Хакатон КАНТКОД тестовое задание
```
Я думаю как поспать
```
Для запуска программы требуется установить LM студию и модель квен 3.5 
После происходит запуск модели в режиме сервера на порту: 1234
Далее запускаем файл Fetch_api.py внутри которого выбираем откуда будут получены входные данные
Следующим запускам Parser.py для очистки от мусора файлов
и в конце запускаем файл AI.py который на базе ИИ квен будет искать противоречия и проблемы в вакансиях
